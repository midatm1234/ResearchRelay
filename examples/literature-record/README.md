# Executed literature collaboration example

This archive was produced by the default ResearchRelay literature demonstration on 2026-11-04. It contains the actual copied source-note inputs, executed Python inventory script, structured outputs, result/review versions, human decision request and derived dashboard snapshot.

The deterministic scripts read the 12 verified, dated seed notes; they do not search the web or call an AI model. Alice and Bob inventory separate groups in isolated Git worktrees. The dependent synthesis is revised after a scripted review requests publication-status and access limitations. A human retains the next-search choice. Scripted review and assessment inputs do not establish scientific validity or productivity gains.

The `literature/` directory also includes the curated bundle navigation/context documents so the copied notes remain understandable outside the web interface. Those proposed follow-up task documents do not launch work.

Git hashes identify the generated local project record, not the application source repository. Data/code bytes are copied exactly and their hashes are checked. SQLite remains authoritative for execution state; dashboard.json and record-manifest.json are exported views. Reproduce a new session with `researchrelay demo --db .runtime/literature-example/state.db --repo .runtime/literature-example/project-record` from an installed source checkout.
