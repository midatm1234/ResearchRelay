# MetaGPT: Meta Programming for A Multi-Agent Collaborative Framework

## Findings

Role-specific standard operating procedures structure intermediate work and verification, with improvements reported on software-engineering benchmarks.[^hong-2024-metagpt]

## Methods

Multi-agent software workflow using role prompts, ordered subtasks, and checks on intermediate outputs.[^hong-2024-metagpt]

## Limitations

Evidence concerns software tasks and evaluated model configurations, not open-ended scientific validity or autonomous assignment of research priorities.

## Implications for ResearchRelay — design inference

Define task outputs and acceptance criteria before execution; make scientific questions explicit rather than embedding decisions in role prompts.
