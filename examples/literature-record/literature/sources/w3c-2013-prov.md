# PROV-DM: The PROV Data Model

## Findings

The model distinguishes produced entities, activities, responsible agents, and derivation relationships.[^w3c-2013-prov]

## Methods

A domain-independent provenance specification with extensible structures, rather than an empirical agent-productivity study.[^w3c-2013-prov]

## Limitations

Provenance descriptions support inspection but do not prove that an activity occurred correctly or that an output is scientifically sound.

## Implications for ResearchRelay — design inference

Record user and agent responsibility, source versions, input/output derivations, and execution evidence without equating provenance with validity.
